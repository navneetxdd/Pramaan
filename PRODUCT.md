# Pramaan — Product Context

**Product:** Multi-vendor DVR/NVR forensic workstation (NTRO SIH26150)  
**Platform:** Desktop-first (Tauri / pywebview) with local FastAPI engine  
**User:** Digital forensic examiner, lab technician, SIH judge demo  
**Primary job:** Acquire disk image → identify OEM → recover deleted footage → timeline/export → custody report  

**Success looks like:** Dense, trustworthy operate UI — like FTK/Magnet, not a landing page. Navy workstation aesthetic with white type and live engine feedback when hashing, carving, or exporting.

**Not in scope for UI:** Cloud sync, marketing signup, social features.
